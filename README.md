# Proyecto_Editor_Audio_ADA
Estación de trabajo de audio digital desarrollada para el curso de Análisis y Diseño de Algoritmos. Reúne cuatro herramientas de procesamiento de señales: detección de transitorios, modificación de tono y duración con phase vocoder, supresión de ruido y agrupamiento de audio por similitud, todas conectadas a un backend en FastAPI.
